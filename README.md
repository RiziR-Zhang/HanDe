daily tracker 是一款 Obsidian 插件，通过每日打卡的方式，记录要保持的习惯。

但——是——，有时我们的行为并不是**做什么**，而是**不做什么**，比如减肥时期某种形式的节食~~（比如戒冲）~~

我们在克制一天不做某种行为后，更有可能**忘了它**而不是提醒自己**睡前打卡**

那怎么办呢？我完成了这个简单的仓库，用来每天自动打卡。只有你打破了习惯，才需要进行显式的动作，告诉系统“今日不要记录”。插件目前面向 windows，因为依赖 Windows tasks scheduler~~（因为作者日用的是 Windows 电脑）~~

+ **如以上述的习惯作为目标**，我认为这种行为更符合人类操作思路
+ 我认为这种行为有助于使用者在打破习惯时增加成本和促进反思，有助于习惯培养
+ 目前项目结构还不成熟

结构：
- src/write_log: 在打破习惯时运行，记录输出到 log
- src/write_file: 每天晚上 23:55 被唤醒，读取 log，在无记录时，将结果输出到 obsidian 和 log
- src/update: 唤醒 write_file
- logs/log.txt: 记录打破习惯和打卡行为（无论有无打卡都有输出）
